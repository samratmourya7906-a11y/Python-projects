About this repository
This repository preserves the original PDF notes supplied for class and adds runnable .py examples organized by topic. The PDFs remain unchanged; the Python scripts are clean, standalone practice examples based on the topics and code patterns shown in the notes.

Organization note: The exact lecture-day sequence was not provided, so the material is arranged topic-wise rather than assigning unverified day numbers. Rename folders to Day-01, Day-02, etc. only if you confirm the actual class sequence.
